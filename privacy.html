개인정보처리방침

시행일: 2026년 10월 30일

1. 접근하는 정보

  • Google 계정 기본 정보: 이름, 이메일 주소, 프로필 사진 — 설정 화면에 연결된 계정을 표시하기 위해 사용합니다.
  • Google 드라이브 파일 (읽기 전용, drive.readonly): 이미지 파일과 폴더 목록, 사진 파일 내용, 촬영 날짜·위치 메타데이터 — 슬라이드쇼와 사진 정보 표시에만 사용합니다.

드라이브의 파일을 수정, 삭제, 업로드하지 않습니다.

2. 저장 위치

앱은 사용자의 컴퓨터에서 직접 실행됩니다. 로그인 토큰, 설정, 화면 표시용으로 축소한 사진 사본은 그 컴퓨터의 앱 폴더에만 저장되며, 개발자를 포함한 다른 서버로 전송되지 않습니다.

3. 제3자 제공

사진에 위치 정보가 있으면 지명을 표시하기 위해 위도·경도 좌표만 OpenStreetMap Nominatim 서비스에 전송합니다. 사진 자체나 계정 정보는 전송하지 않습니다. 그 밖에 어떤 정보도 제3자에게 제공하거나 판매하지 않으며, 광고에 사용하지 않습니다.

Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 삭제

설정 화면의 연결 해제를 누르면 저장된 로그인 토큰과 사진 사본이 삭제됩니다. Google 계정 권한 페이지에서도 언제든지 앱의 접근 권한을 해제할 수 있습니다.
